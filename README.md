# Social Media App

A simple social media application built with JavaScript and the Noroff API.

## Description

This project is a frontend social media application where users can register, log in, view posts, create and edit their own posts, search for posts and users, and follow or unfollow other users.

The project was created as part of the Front-end Development course at Noroff.

## Features

- Register a new user
- Log in and log out
- View all posts
- View individual posts
- Create posts
- Edit own posts
- Delete own posts
- Search posts
- View own profile and posts
- Search for other users
- View other users' profiles and posts
- Follow and unfollow users

## Getting Started

### How to run the project

2. 1. Clone the repository:
   `git clone https://github.com/susannt/social-media-app.git`

2. Navigate to the project folder:
   `cd social-media-app`

3. Install the dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`

5. Open the local URL shown in the terminal.
